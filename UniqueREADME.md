# Mad Libs Generator (AP CSA Project)

A Java-based interactive Mad Libs story generator created for AP Computer Science A. This program parses a template string, prompts the user for specific parts of speech, and dynamically constructs a completed story using AP CSA-compliant String manipulation algorithms.

---

## 📋 Requirements & Features

- **AP CSA Java Subset Compliant:** Uses only `String` methods allowed on the AP CSA Quick Reference (e.g., `indexOf`, `substring`, `length`).
- **Dynamic Parsing Algorithm:** Identifies placeholder tags within the story template and replaces them with user inputs.
- **Interactive Prompts:** Guides the user with clear instructions to enter required parts of speech (nouns, verbs, adjectives, etc.).
- **Clean Code Standards:** Features camelCase naming conventions, clear algorithm comments, and a structured `main` method.
